# Agent rules

## Commits

- English only.
- One line, Angular style: `feat: ...`, `fix: ...`, `test: ...`, `chore: ...`, `docs: ...`,
  optionally scoped: `feat(rules): ...`.
- Short and compact. No body, no `Co-Authored-By` trailer, no session links.

## HTML pages

- Never publish web pages as claude.ai artifacts. Write the HTML file locally in the
  repo and open it with `open <file>`.

## Scope

- This project is standalone. It does not depend on, borrow from, or coordinate
  with any other repository (e.g. `hdl-format`, `verilog-rtl`). Tool versions
  such as the Verible pin are decided here alone.
